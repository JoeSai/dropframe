# 掉帧

观众在哪一秒走的，对着画面看。

抖音创作者中心能导出每条作品的「内容吸引力数据」，里面有逐秒留存和同类作品对比，但只是一列数字。把它和成片一起拖进「掉帧」，你会看到：

- 每一秒一张画面，排在留存曲线下面；
- 哪几秒走掉的观众比同类作品多，颜色越深，多走得越多；
- 最该改的 3 秒，点一下就从那里播放；
- 这 3 秒可能的原因：画面变化太快、几乎没动、切镜、黑屏白屏、没有声音、比平时安静。

视频和数据只在你的浏览器里处理，不上传。

## 怎么用

1. 抖音创作者中心 → 内容管理 → 点开一条作品 → 流量分析 → 「内容吸引力」右上角「导出」，得到一个 `.xlsx`。
2. 打开「掉帧」网页 https://joesai.github.io/dropframe/ ，把这个 `.xlsx` 和这条作品的成片一起拖进去。

没有数据也可以先点「用示例试试」，用一条示例作品看看效果。

## 本地运行

不需要安装依赖，任何静态服务器都行：

```bash
python3 -m http.server 5178
```

然后打开 http://localhost:5178 。

## 怎么算的

导出表里的「留存」是到第 N 秒还在看的观众比例。第 k 秒（k−1 到 k 之间）走掉的观众 = 第 k−1 秒的留存 − 第 k 秒的留存。拿它和同类作品同一秒走掉的比例相减，多走 1 个百分点以上的秒会标出来，多走最多的 3 秒列在「最该看的几秒」里。胶片条上每一格是这一秒中间（k−0.5 秒）的画面。

原因是本地规则判断的，不用 AI 模型：每秒取 4 张小图，比较相邻两张差多少（画面动没动、切没切镜、亮度），再算这一秒的音量，和全片平时的音量比。
